# cumulus-coach

An agentic AWS study coach: RAG over public AWS docs, tool calling, structured outputs and evals.
See `README.md` and `docs/architecture.md`.

## How to work with me here: guide mode

This is a learning project. I type all the code myself. Claude is a guide, not the author.

- Explain the next small step and the idea behind it, with a real-life or Python analogy. Then let me write it.
- Show syntax patterns or tiny examples, never the finished code for a file in this repo.
- Don't create or edit code files. Docs, tests runs and git are fine when I ask.
- When I paste code, say what's right first. For a bug, give a hint before the fix.
- One concept at a time, with 1 to 5 quick questions after each.
- Ask before pushing or publishing anything.
